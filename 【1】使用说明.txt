==============================================
企业生产经营离线分析 - 免安装便携版使用说明
==============================================

【一句话】
先解压整个文件夹（务必整包解压，别只解压出单个文件），
然后双击「【2】可视化数据分析.bat」，浏览器会自动打开
http://localhost:8501 即可使用。

-----------------------------------------------
【重要】本包自带运行环境，无需安装任何东西
-----------------------------------------------
- 无需安装 Python，无需联网。
- python\ 文件夹是内置的运行环境，请勿改名、移动或删除。
- 程序完全在本地运行，数据不离开你的电脑。

-----------------------------------------------
【如何放置数据】
-----------------------------------------------
把 Excel（.xlsx 或 .xls）放进 data\ 文件夹，可按年份分子文件夹：
    data\2025\年度报告记录 (地区名).xlsx
    data\2025\年度报告记录 (地区名1).xlsx   (分卷，自动合并)
    data\2026\年度报告记录 (地区名).xlsx
表头需包含 12 项业务字段（列名顺序不限；真实报表可能前两行为
标题/空行，程序会自动识别表头）：
    是否股权转让、是否对外投资、
    资产总额、所有者权益合计、销售额或营业收入、利润总额、
    营业总收入中主营业务收入、净利润、负债总额、纳税总额、
    资产认缴额、资产实缴额
（示例演示数据已放在 data\2025、data\2026，可直接体验。）

-----------------------------------------------
【如何启动 / 停止】
-----------------------------------------------
- 启动：双击「【2】可视化数据分析.bat」，等浏览器出现页面。
- 停止：直接关闭弹出的黑色命令行窗口。
- 更新数据后，在页面左侧点「🔄 重新加载数据」即可。

-----------------------------------------------
【输出物】
-----------------------------------------------
不再于启动时自动生成；在「📤 报告导出」页点击
「导出 分析结果汇总.xlsx」即可下载（含明细、地区汇总、
公示分布三个工作表），可直接离线查看。

-----------------------------------------------
【网页里的「报告导出」标签页】（推荐）
-----------------------------------------------
面板右侧第三个标签页「📤 报告导出」，页面上方即可：
- 「导出 分析结果汇总.xlsx」按钮（备查表不再自动生成）；
- 选「方式A / 方式B」进入各自操作页：
  - 方式A 页：勾选/关闭模块（总体情况、经营指标、增长率、
    公示分布）；用 ▲/▼ 上下移动调整顺序（标号自动按
    一、二、三… 生成）；自选呈现样式（表格 / 柱状图 / 折线图）；
    勾选要隐藏字段（默认隐藏纳税总额、负债总额、资产负债率、
    销售净利率、净利润率、环比增长率）；填封面后一键生成下载；
    还可保存设置为「报告设置.json」让 CLI 与下次默认生效。
  - 方式B 页：生成「报告填写表单.xlsx」模板并下载，或上传
    已填写好的表单直接生成 Word 报告（顺序/样式/字段在表单
    「报告设置」「字段显示」工作表设置）。

-----------------------------------------------
【Word 报告导出】（离线，推荐用网页）
-----------------------------------------------
报告生成主要在面板「📤 报告导出」页完成（方式A / 方式B 分页，
见上文），无需命令行。

如需命令行，可直接运行（本机须已装有 Python）：
  python make_report.py -a                方式A：自动生成报告
  python make_report.py -f                生成「报告填写表单.xlsx」
  python make_report.py 报告填写表单.xlsx  方式B：按表单生成报告

图表：
- 默认自动生成（离线），无需网络。
- 想自定义：把图片放到 report_img\ 并按「图表名称.png」命名，
  或在「图表映射.txt」写「图表名称=图片路径」（方式A）；
  方式B 在表单「图片设置」工作表：是否自定义填「是」+ 图片路径。
- 图表名称（4 个）：总体情况图、经营指标图、增长趋势图、公示分布图。

-----------------------------------------------
【常见疑问】
-----------------------------------------------
- 杀毒软件或系统提示：这是本机运行的程序，选择「允许/仍要运行」即可。
- 双击没反应：右键对应 .bat →「以管理员身份运行」再试。
- 端口被占用（显示 There is already a server running）：
  说明你已开过一个，先关掉之前的黑窗口，或稍等再开。
