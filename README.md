# 企业生产经营离线分析

本地离线运行的**地区维度**企业生产经营分析工具：读取多个 Excel 数据文件（支持 **.xlsx 与 .xls**、按年份分子文件夹），自动合并、按**整个地区**聚合计算核心经营指标，通过 **Streamlit 交互面板**（两个标签页）与**静态 Excel 备查表**展示分析结果。

> 本项目只做**地区整体**分析，不按单个企业维度输出（不依赖企业名称列）。
> 本包为**免安装便携版**：自带 Python 运行环境，无需安装、无需联网，解压后双击即可运行。

## 快速开始（免安装）

1. **整包解压**本文件夹（务必整包解压，勿只解压单个文件）。
2. 双击 **「启动分析.bat」**。
3. 浏览器自动打开 `http://localhost:8501` 即可使用。
4. 停止：直接关闭弹出的黑色命令行窗口。

> - 内置运行环境位于 `python\` 文件夹，请勿改名、移动或删除。
> - 更新数据后，在页面左侧点「🔄 重新加载数据」即可。
> - 详细说明见同目录「【使用说明】.txt」。

## 功能

- **自动读取合并**
  - 递归扫描 `data/` 下的 Excel（支持 `.xlsx` 与 `.xls`），支持按**年份分子文件夹**（如 `data/2025`、`data/2026`），年度取自文件夹名（表头含「年度」列时以表头为准）。
  - 文件名：`年度报告记录 (地区名).xlsx/.xls`（英文括号，可带空格）；同一地区拆多卷时：`年度报告记录 (地区名1)`、`年度报告记录 (地区名2)`，同一地区的多个分卷自动合并。
  - 同一地区内同一年度多条记录（含跨分卷出现）按数值字段加总；完全重复行自动去重。
- **地区维度指标**（按「地区 × 年度」整体计算）
  - 销售净利率 = 净利润 / 销售额
  - 净利润率 = 净利润 / 营业收入
  - 净资产收益率（ROE）= 净利润 / 所有者权益合计
  - 主营业务收入占比 = 主营业务收入 / 营业收入（占比低提示依赖非主营、经营稳定性可能较差）
  - 总资产周转率 = 营业收入 / 平均资产总额（平均资产 =（上年末 + 当年末）/2，无上年时用当年末；周转快说明运营活跃、产能利用率高）
  - 增长率（同比与环比，年度数据下两者相同）：销售额、净利润、资产总额、主营业务收入四类，按**地区**分组、严格相邻年度计算；上年缺失 / 断档 / 为 0 时记 NA，避免除零。
  - 净利润率趋势：地区整体净利润率能否计算、是否总体上升；上升时提示「营收扩张、资本扩张、利润增长」；无法计算时记 N/A。
  - 标准差（销售额、净利润）：地区各年度数值的样本标准差，衡量地区经营波动。
- **公示状况**（按每一行 = 一家企业，12 项判定，再聚合为**地区公示分布**）
  - 12 项：是否股权转让、是否对外投资、资产总额、所有者权益合计、销售额或营业收入、利润总额、营业总收入中主营业务收入、净利润、负债总额、纳税总额、资产认缴额、资产实缴额
  - 全部公示：12 项均无空位；部分公示：存在空位（未全空）；全部不公示：全部为空位（数值为 0 一律视为空位）
  - 可视化标签页展示各地区内「全部 / 部分 / 全部不公示」企业数量统计。
- **交互面板**（Streamlit + Plotly）
  - 标签页 1「可视化分析」：按**地区** / 年度范围筛选；地区整体净利润率、ROE 趋势折线图；最新年度各地区盈利对比柱状图；销售额 / 净利润趋势；地区 × 年度汇总统计表；企业公示分布表。图表支持缩放、悬停查看数值。
  - 标签页 2「文本报告」：按**地区**生成经营总结（盈利能力、增长趋势、扩张判断、主营占比提示、亏损但周转快提示、异常数据提示、公示统计），可下载。
- **静态备查**：启动后自动生成 `分析结果汇总.xlsx`，含「地区年度明细」「地区汇总」「公示分布」三个工作表，离线查阅。

## 数据准备

把 Excel（.xlsx 或 .xls）放入项目根目录 `data/`（可按年份分子文件夹）：

```
data/2025/年度报告记录 (示范镇A).xls
data/2025/年度报告记录 (示范镇A1).xlsx   ← 分卷，自动与同地区合并
data/2025/年度报告记录 (示范镇B).xlsx
data/2026/年度报告记录 (示范镇A).xlsx
```

表头应包含 **12 项业务字段**（列名顺序不限，支持常用别名；不含「年度」列时用年份文件夹；不依赖企业名称列）：

| 字段 |
|---|
| 是否股权转让 |
| 是否对外投资 |
| 资产总额 |
| 所有者权益合计 |
| 销售额或营业收入 |
| 利润总额 |
| 营业总收入中主营业务收入 |
| 净利润 |
| 负债总额 |
| 纳税总额 |
| 资产认缴额 |
| 资产实缴额 |

`sample_data_generator.py` 可生成一套演示数据（年份文件夹、分卷、跨卷加总、缺年度、公示三态），便于开箱体验（数据均为虚构）。`data/2025`、`data/2026` 已含演示数据，可直接体验。

## 计算口径说明

- 增长率按「地区」分组、按年度升序，仅与上一个实际出现且相邻的年度比较；年度断档、上年缺失或上年为 0 时记 NA。
- 比率类指标分母为 0 或缺失时记 NA，不产生除零错误。
- 标准差为地区各年度数值的样本标准差（仅一个年度时为 NA）。
- 所有判断与结论均基于实际计算数据动态生成，代码不含任何硬编码的地区名 / 年份 / 企业名。
