# 企业生产经营分析

本地离线运行的企业生产经营分析工具：读取多个 Excel 数据文件，自动合并计算核心经营指标，通过 **Streamlit 交互面板**（两个标签页）和 **静态 Excel 备查表** 展示分析结果。

## 功能

- **自动读取合并**：扫描 `data/` 下符合命名规则的 Excel（`年度报告记录（地区名）.xlsx`，数字为分卷号），同一地区的多个分卷自动合并；同一企业同一年度的多条记录按数值字段加总，完全重复行自动去重。
- **核心指标计算**：
  - 销售净利率 = 净利润 / 销售额
  - 净利润率 = 净利润 / 营业收入
  - 净资产收益率（ROE）= 净利润 / 所有者权益合计
  - 销售额 / 净利润 同比与环比增长率（年度数据下两者相同，按实际相邻年份计算；上年缺失或为 0 时标记 NA，避免除零）
  - 销售额标准差、净利润标准差（按企业各年度，衡量经营稳定性）
  - 补充指标：资产负债率、总资产周转率、主营业务占比
- **交互面板**（Streamlit + Plotly）：
  - 标签页 1「可视化分析」：按地区 / 企业 / 年度范围筛选；净利润率、ROE 趋势折线图；同年度企业 ROE 对比柱状图；汇总统计表。图表支持缩放、悬停查看数值。
  - 标签页 2「文本报告」：按地区或企业动态生成经营状况文字总结（含盈利能力、稳定性、增长趋势与异常数据提示），可下载。
- **静态备查**：自动生成 `分析结果汇总.xlsx`（含「明细」「企业汇总」两个工作表），方便离线查阅。

## 快速开始

1. 安装 Python 3.8+（Windows 安装时勾选 "Add Python to PATH"）。
2. 双击 `run.bat`，首次运行会自动安装依赖（`pip install -r requirements.txt`），之后完全离线使用。
   - 或手动：`python -m pip install -r requirements.txt` → `python -m streamlit run app.py`
3. 浏览器打开 `http://localhost:8501`。

## 数据准备

把 Excel 文件放入项目根目录的 `data/` 文件夹，文件名格式：

```
年度报告记录（地区名）.xlsx
年度报告记录（地区名1）.xlsx    ← 数字表示分卷，自动与同地区其他分卷合并
```

表头固定为：

| 列名 |
|---|
| 企业名称 |
| 年度 |
| 资产总额 |
| 所有者权益合计 |
| 销售额或营业收入 |
| 利润总额 |
| 营业总收入中主营业务收入 |
| 净利润 |
| 负债总额 |

`sample_data_generator.py` 可生成一套演示数据，便于开箱体验（数据均为虚构示例）。

## 目录结构

```
├── config.py            # 配置：路径、文件名规则、字段名、指标口径
├── file_loader.py       # 读取、解析地区与分卷、合并去重
├── analysis.py          # 指标计算（含严格相邻年度增长率、除零保护）
├── report_generator.py  # 静态 Excel 与动态文字报告
├── app.py               # Streamlit 交互面板
├── run.bat              # Windows 一键启动
├── requirements.txt     # 依赖清单
├── 使用说明.txt          # 部署与使用说明
├── sample_data_generator.py  # 可选：生成演示数据
└── data/                # 数据目录
```

## 计算口径说明

- 增长率按「地区 + 企业」分组、按年度升序，仅与**上一个实际出现且相邻的年度**比较；年度断档、上年缺失或上年为 0 时记 NA。
- 比率类指标分母为 0 或缺失时记 NA，不产生除零错误。
- 标准差为企业各年度数值的样本标准差（仅一个年度时为 NA）。

## 说明

- 完全离线：所有库均为本地依赖，Streamlit 为本地框架，不调用任何网络 API。
- 所有街道 / 地区名、年份、企业名均从数据中动态提取，代码不含任何硬编码。
- 示例数据与企业名均为虚构演示内容。
