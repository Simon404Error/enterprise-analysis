------------------------------------------------
【第一步】安装 Python（仅首次）
------------------------------------------------
1. 到 https://www.python.org/downloads/ 下载 Python 3.8 或更高版本（Windows 版）。
2. 安装时务必勾选 "Add Python to PATH"（加入系统路径）。
3. 验证：打开 cmd，输入 `python --version`，能显示版本号即成功。

------------------------------------------------
【第二步】放置数据
------------------------------------------------
把 Excel 文件放到本项目的 data\ 文件夹中。
文件名必须符合规则：
    年度报告记录（地区名）.xlsx
    年度报告记录（地区名1）.xlsx   ← 数字 1 表示分卷
例如：
    年度报告记录（示范镇A）.xlsx
    年度报告记录（示范镇B）.xlsx
    年度报告记录（示范镇B1）.xlsx   ← 与上一文件合并（同一地区分卷）
表头固定为：
    企业名称、年度、资产总额、所有者权益合计、销售额或营业收入、
    利润总额、营业总收入中主营业务收入、净利润、负债总额

------------------------------------------------
【第三步】启动
------------------------------------------------
双击 run.bat（首次运行会自动 pip install 依赖，需联网装一次；
装完后完全离线使用）。

或手动：
    python -m pip install -r requirements.txt
    python -m streamlit run app.py
浏览器打开 http://localhost:8501 即可使用。

------------------------------------------------
【功能】
------------------------------------------------
- 标签页「可视化分析」：按地区 / 企业 / 年度筛选；
  净利润率、ROE 趋势折线图；同年度企业 ROE 对比柱状图；汇总统计表。
- 标签页「文本报告」：按地区或企业生成经营状况文字总结（可下载）。
- 静态备查：自动生成「分析结果汇总.xlsx」（明细 + 企业汇总两个工作表）。

------------------------------------------------
【计算口径】
------------------------------------------------
- 销售净利率 = 净利润 / 销售额
- 净利润率   = 净利润 / 营业收入（同销售净利率口径）
- ROE        = 净利润 / 所有者权益合计
- 同比/环比增长率：年度数据，两者相同，与上一个实际出现的年度相比；
  上年缺失或为 0 时显示 NA，避免除零。
- 标准差（销售额/净利润）：企业各年度数值的样本标准差。
- 同一企业同一年度多条记录：数值字段加总合并。
